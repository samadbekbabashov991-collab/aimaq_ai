# AIMAQ AI — Жергілікті мәселелерді анықтау, талдау және бақылау платформасы (MVP Prototype)

**Ш. Уәлиханов атындағы Көкшетау университеті — «StartUp Project AI 2026» байқауына арналған прототип**

**AIMAQ AI** — тұрғындардан, ұйымдардан және ашық арналардан (веб-портал, Telegram-бот) келіп түсетін жергілікті инфрақұрылымдық мәселелерді бір жүйеге жинап, жасанды интеллект көмегімен санаттайтын, қайталанатын шағымдарды біріктіретін және жауапты қызметке бағытталатын құрылымдалған тапсырма қалыптастыратын цифрлық платформа.

---

## Негізгі мүмкіндіктер (MVP)

1. **Тұрғындарға арналған жеңіл өтініш беру (Веб + Telegram-бот симуляторы):**
   - Жол шұңқыры, көше жарығы, қоқыс жиналуы, су құбыры немесе қоғамдық кеңістік ақаулары туралы мәтін, фото және мекенжай/геолокация жіберу.
   - Қазақ және орыс тілдеріндегі өтініштерді қолдау.
2. **AI-талдау және қайталанатын шағымдарды біріктіру (Deduplication):**
   - Бір аудан/санат бойынша түскен ұқсас өтініштерді бір оқиғаға біріктіру (`x2`, `x4` кластерлер) және қайталану тығыздығына қарай басымдық деңгейін ұсыну.
3. **Human-in-the-Loop (Маман растайтын басқару панелі):**
   - AI соңғы шешімді өздігінен қабылдамайды — жауапты диспетчер/маман басымдықты тексеріп, наряд-тапсырманы бекітеді және орындалу мәртебесін бақылайды.
4. **B2G / B2B Құндылық және SaaS моделі:**
   - Ауылдық округтерге, аудан/қала әкімдіктерінің ТКШ бөлімдеріне және сервистік/басқарушы ұйымдарға арналған айлық/жылдық жазылым және енгізу моделі.

## Жоба құрылымы

```text
aimaq-ai-prototype/
├── index.html               # Толық интерактивті MVP веб-прототип (Frontend, тәуелділіксіз іске қосылады)
├── backend/
│   ├── main.py              # FastAPI серверлік API прототипі (өтініш қабылдау, AI санаттау, кластерлеу)
│   └── requirements.txt     # Python тәуелділіктері
├── .gitignore               # Git үшін қажетсіз файлдарды сүзу
└── README.md                # Жоба сипаттамасы және іске қосу нұсқаулығы
```

---

## Іске қосу жолы

### 1. Веб-прототипті бірден ашу (Frontend)
`index.html` файлын браузерде тікелей ашыңыз немесе VS Code **Live Server** / кез келген статикалық сервер арқылы іске қосыңыз.

### 2. Backend API-ды іске қосу (FastAPI — міндетті емес, кеңейту үшін)
```bash
cd backend
pip install -r requirements.txt
uvicorn main:app --reload
```
API құжаттамасы: `http://127.0.0.1:8000/docs`

---

## Технологиялық стек
- **Frontend:** HTML5, CSS3, Vanilla JavaScript (Responsive UI)
- **Backend (жоспарланған/базалық API):** Python, FastAPI
- **Дерекқор (масштабтау кезінде):** PostgreSQL + PostGIS
- **AI / Интеграция:** NLP мәтін санаттау, Computer Vision фото талдау, Telegram Bot API, OpenStreetMap
